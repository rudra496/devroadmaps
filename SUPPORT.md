# Support

## Getting Help

### Documentation
- Read the [README](README.md) for setup and usage instructions
- Check the [FAQ](#faq) section in the README
- Browse the [roadmaps](roadmaps/) directory for available career paths

### Issues
- **Bug reports:** Open an issue with the `bug` label and include steps to reproduce
- **Feature requests:** Open an issue with the `enhancement` label
- **Broken links:** Open an issue with the `bug` label and include the broken URL

### Discussions
For questions, ideas, or general discussion, open a [GitHub Discussion](https://github.com/rudra496/devroadmaps/discussions) if available.

## Community

- Contribute new roadmaps or resources — see [CONTRIBUTING.md](CONTRIBUTING.md)
- Report security issues privately — see [SECURITY.md](SECURITY.md)

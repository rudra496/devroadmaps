# Changelog

All notable changes to DevRoadmaps are documented in this file.

## [2.0.0] - 2025-06-05

### Added
- **3 New Roadmaps**: Cloud Architect, Platform Engineer, Site Reliability Engineer (SRE)
- **AR/VR Developer Roadmap**: Latest roadmap covering AR/VR development
- **Low-Code/No-Code Roadmap**: Beginner-friendly path for no-code builders
- **Technical Writer Roadmap**: Career path for technical documentation
- **QA/Test Engineer Roadmap**: Comprehensive testing career path
- **DevSecOps Engineer Roadmap**: Security-focused DevOps career path
- **Daily Challenges**: New coding challenge every day with streak tracking
- **Skill Radar Chart**: SVG-based visual progress across all skill areas
- **Project Ideas**: Curated hands-on project ideas for each career path
- **Interview Prep**: Practice with curated interview questions and answers
- **Roadmap Comparison**: Compare any two roadmaps side by side
- **Shareable Progress Cards**: Generate beautiful PNG cards to share on social media
- **Learning Notes**: Per-roadmap personal learning journal
- **Command Palette**: `Ctrl+K` quick navigation to any roadmap or feature
- **Community Forum**: Local discussion board for learners
- **Certification Tracker**: Map progress to real exam topics (AWS, GCP, CKA, Security+, etc.)
- **Learning Paths**: Pre-built paths combining nodes from multiple roadmaps
- **Bookmarks**: Save topics across roadmaps and export as a study plan
- **Data Export/Import**: Backup and restore all learning data
- **PWA Support**: Service worker for offline capability

### Changed
- Expanded from 6 to 20 roadmaps
- Updated topic count from ~300 to 920+
- Expanded free resources from ~600 to 2,000+
- Redesigned landing page with glassmorphism UI
- Added dark/light/auto theme support
- Improved keyboard navigation throughout

## [1.0.0] - 2025-01-15

### Added
- Initial release of DevRoadmaps
- 6 roadmaps: Frontend, Backend, Full Stack, ML/AI, DevOps, Mobile
- Interactive progress tracking with localStorage
- Search and filter by category and difficulty
- Dark and light mode
- Print-as-poster functionality
- Fully responsive design
- Community tips and resource ratings
